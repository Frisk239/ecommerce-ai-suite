# 第四阶段 roadmap：体系完整化与真实使用（2026-09-16 立项）

日期：2026-09-16。来源：Owner grill 会话逐项签核。名词溯源：「懂王Ai 口径」=B 站 UP 主「懂王Ai」的电商 AI 体系主张（8 项目以数据中台为核心，2026-09-16 两期视频实测转写）；「Q1–Q10」=该 grill 会话十组裁决的编号，**裁决结论已全部落进本文件各刀，无需回查会话记录**。状态：**Owner 立项，施工权威**——第三阶段（`docs/roadmap-product-hardening.md`，41–48 刀）已收官并降级为存档。

## 北极星

**真实使用一次贯穿，懂王口径逐项可指代码，证据纪律不松反紧。**三条验收线：

1. **戏台完整**：懂王口径 8+1 项（AI 客服 / RAG 知识库 / 数据中台 / 多模态素材 / 直播切片 / 销售考核 / 微调数据供给 / MCP 架构 / 自媒体内容）每项有对应模块且可演示或可指文件——其中「微调数据供给」以**数据集导出**形态满足，产品仍不训练；「多模态素材」以**图片治理 + 媒体引用回答 + 直播洗帧的内容自循环**（94a/b/c）+ **内容配图生成**（98，IMGGEN——素材成品面）满足，**知识证据面图生成仍 Out**。
2. **真实使用**：一个真实运营的数码外设「店」——开放数据集灌入 + 店主自写政策口径 + widget 挂公网静态页 + 真实问法 50+ 条 + 拒答飞轮真转一圈 + 直播源录像过 ASR→拣选→真切→客服拉切片全链路；产出使用日志与实测数字。
3. **证据纪律**：每刀 CI 全量绿；动检索/生成必 before/after 同报告（`docs/research/rag-eval-report.md`）；**数据灌入/订正类刀必重跑基线并逐位对账**（审计刀 15 机制约束）；工具语义变更必 ADR；真实使用问法回流评测集。

### 第 94a 刀：图片资产活化 + 商品素材视图（必开 ADR）

- 内容：迁移给图片资产加**「图片描述」治理字段**（video.transcript 同构：人洗补写生效，描述切块进检索索引——图片从此可被命中）；`VLM_API_KEY/VLM_BASE_URL/VLM_MODEL` 独立 env——VLM 看图出**描述草稿**（人确认才生效，LLM 只出草稿不出事实；未配置=纯人洗补写兜底，fail-诚实）；**商品详情页加「素材」聚合段**——该商品关联的图/视频/文案素材卡（来源/版本/状态），素材库不建独立页（资产列表+来源筛选已存在），聚合做在商品维度；图片来源双轨：运营上传为主 + Pexels 辅轨拉产品展示图（Pexels 本以图库为主；89 刀 Pexels key 债一并清——视频辅轨用途仍按 89 刀定案留给录像线）。**第 98 刀随刀订正：内容配图生成已由本刀打开（IMGGEN_* env，产物走质检管道）；知识证据面 AI 生图仍 Out**（要当证据必须走 94a 人洗描述治理）。Pexels 辅轨拉图仍留使用剧本。
- 词条候选：**图片描述**（人洗确认后生效的检索文本面）。spec_schema 补 image(P18)/website(P856) 字段（89 刀定案未随 90 落地，审计刀 18 补记归此刀）。
- 验收：上传商品图→补描述→发布→顾客问图片内容词命中该资产（e2e）；Pexels 辅轨图带许可落库。

### 第 94b 刀：媒体引用回答（必开 ADR）

- 内容：检索命中图片/视频类资产时 `complete` 载荷新增 `media_citations: [{asset_id, version_no, mime}]`——**服务端定，模型无决定权**（与 citations 同纪律）；媒体字节端点 `GET /api/customer/assets/{id}/media`（顾客令牌/操作者 cookie 鉴权、只出已发布指针版、图片直出/视频支持 Range；不暴露对象存储路径）；文本回答纪律不变（描述/transcript 证据照常组装/生成，拒答与覆盖闸照旧）；客服页与 widget 端渲染（图片直出、视频播放器）。
- 词条候选：**媒体引用**。
- 验收：命中切片的回答带可播附件、命中图片的回答带图；未发布/废弃版本媒体端点拒绝的钉测。

### 第 94c 刀：直播洗帧（必开 ADR）

- 内容：对已发布视频资产触发「洗帧到素材库」——均匀采样（每 5s 一帧、≤24 帧）+ VLM 逐帧打分挑商品特写/清晰帧（≥6 分成候选、≤8 帧；**94c 实现订正**：立项假设「按转写句时间戳定位」不成立——资产 transcript 是纯文本无时间戳，句定位无数据可依，ADR 0053），每候选=时间点+分数+VLM 一句话+帧预览；**人工拣选闸门**（与切片拣选同款交互，「自动候选+人工确认」模式第三次复用——ASR 候选/评论回流先例）；确认帧登记为独立图片资产（字节=该帧 jpg；新来源词 `clip_frame`），血缘可见「切自哪个视频资产」（回执 cut_from+来源词+标题承载，与切片回执同追溯模式）；登记后走 94a 通用治理（VLM 描述草稿→人确认→进索引）→ 94b 可引用。**帧不是视频资产的版本，是独立资产**；全自动直接入库被否（发布权在人，对帧破例即破治理故事）。
- 验收：一段已发布切片洗出 ≥1 张商品帧→描述确认→顾客问商品图命中该帧资产。

### 第 98 刀：自媒体内容套件（模板+配图生成+质检双闸）

  ① `gen_material` 加产物模板参数（站内投放文案/小红书笔记体/短视频口播稿）——仍只是 prompt 模板参数，不是 Agent、不加 planner（运营不是 Agent 的 ADR 不动）；
  ② **配图生成**：文生图云 API（独立 `IMGGEN_API_KEY/IMGGEN_BASE_URL/IMGGEN_MODEL` env，未配置=配图步骤诚实跳过，fail-closed）——按文案模板生成配套图（小红书头图/图文推送配图），**产物与文案同走素材中心质检管道**（规则+LLM 双闸→人抽检→登记 material 资产，配图字节进对象存储）；
  ③ 规则质检过线后加 LLM 事实性质检二道闸（同机洗调用模式，失败不进待抽检，人抽检保留）。
- 分层红线：生成图是**素材成品**（可被运营编排/内容成片引用），**不是知识证据**——不进检索索引；要当证据必须走 94a 描述治理（人洗确认）。
- 必开 ADR：质检双闸 + 配图生成分层口径（内容面/知识面）。
- 验收：三种模板「文案+配图」套件各一套真实生成记录；质检二道闸拦住一条构造的幻觉规格样本（钉测）；无 IMGGEN key 时套件降级为纯文案（诚实提示）。

### 第 98b 刀：内容成片引擎 v1（草稿优先双层，必开 ADR）

- 背景（2026-09-16 调研钉死）：懂王口径的「剪辑 Agent」=直播切片（知识面），**无投放成片形态**——本刀是对其口径的自觉外延（差异化卖点）；行业验证形态=「AI 生成可编辑工程文件→人审改→上市」（pyJianYingDraft 草稿线），与「自动候选+人工闸门」完全同构。
- 内容：
  ① **AI 层（选材+排版）**：运营选商品 → 从**已发布**素材自动选材（配图 98 产物/商品图/切片片段/文案要点）+ 按模板排时间线 → 产出两件东西：**剪映草稿工程**（pyJianYingDraft，人可打开精修）+ **ffmpeg 简易预览成片**（图序列+TTS 口播+字幕，15–60s，供浏览器内快速看效果）；
  ② **人闸门**：审改后的成品**上传回素材中心登记**（material 资产，可被运营编排引用投放）——AI 排版、人上市；
  ③ TTS 走云 API（复用 ASR 同供应商思路，独立 env；未配置=预览成片无音轨并诚实标注）；
  ④ 直播高光成片=本刀的一个**模板入口**（从已发布切片挑高光串集锦），不单立模块。
- 红线（进 ADR）：AIGC 生成内容显式标识（《人工智能生成合成内容标识办法》）；素材来源白名单（自有拍摄/运营上传/开放许可/已授权切片——不爬平台回放）；口播与字幕文案**复用质检双闸**（禁词/功效宣称/价格口径）；数字人与声音克隆 Out（人格权）。
- 验收：一条真实成片全链（选材→草稿+预览→人确认→登记 material 资产）；预览成片带 AIGC 标识；草稿工程可被剪映打开（形态断言）。
- 依赖：98（文案+配图）、94a/c（素材图来源）。图文转视频（候选 B）列观察项押后。

### 第 99 刀：MCP 活状态只读工具刀（必开 ADR）

- 内容：`get_product`（含价格/规格）/ `get_stock` / `get_order_status` 三工具——**复用客服在用的 catalog_tools/stock_tools/order_tools 同一套函数**；协议证据断言「恰四工具」改「恰七工具、仍无 publish」（pytest + smoke 同步）；ADR 写脱敏边界：当前订单 mock 无 PII、返回不含联系方式，真实部署需单号+手机尾数双因子核验的升级路径。
- 验收：外部客户端七个工具全列表；订单返回无 PII 字段的钉测。

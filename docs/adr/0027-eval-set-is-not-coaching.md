# 评测集和销售考核分开；评测集是派生视图

拿销售考题给微调前后打分，人的分数和引擎质量会搅在一起。把评测集升格成中台对象，又多一个不能发布的主数据。没有评测集则能力闭环只剩两个口吻开关。

考核抽已发布对话，训练并打分的是人。评测集是问题 + 期望引用或拒答，只读已发布，用来对比基座/微调、回归检索。不是资产。v1 可以是一份可复现记录加客服切模型，不必做评测台。

回写（第 16 刀）：期望除引用/拒答外，也可为工具形状（工具名+摘要锚，`tool/tool_summary_contains`）——第 13/14 刀订单与库存工具（ADR 0036/0037）的自然延伸，runner 直调 run_ask 走真实分派路径，工具形状同样只读已发布+种子数据，评测集「不是资产、不是考核」的定性不变。

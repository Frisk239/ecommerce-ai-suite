# v1 不做模型微调；推理只走厂商 Chat API

推理已锁定为厂商大模型 API。再做训练任务、LoRA 或「基座/微调」开关，要么绑死在厂商 Fine-tune 接口上，要么是进度条演戏。多数商家没有训练班底；本产品的分量在中台治理和检索，不在自备权重。

砍掉业务能力「模型微调」。客服生成只调厂商 Chat/Completions。不做训练作业、不托管适配器、不在客服里切微调底座。模型配置只保存厂商接入（地址、模型名、密钥位）。MCP 仍可导出已发布资产，那是给外部系统的数据包，不叫微调集。评测集（ADR 0027）只用于回归检索和拒答，不对比微调前后。RAG 不够时走知识缺口（ADR 0024）再发布，不走训练。

# 写回按版本全量，不叠加；回滚即回口径

状态：审计刀产出（修复「回滚后指针 v1、商品值混 v2」的不一致），PR review 把关。映射 0010（发布写回确认字段）+ 0006（指针语义），无新对象。

## 语义

商品上**该资产写过的字段**与该资产的**当前已发布版本**保持一致：

- 发布/回滚移动指针后，写回 = 该版本确认字段（∩ 商品 spec_schema）的**全量快照**。
- 本资产旧版本写过、新版本没有的字段 → 清除（商品显示 —），不残留旧口径。
- **其他资产**写回同一商品的字段不受影响（多资产挂同商品时各管各的口径）。

## 动机

审计发现 `_write_back_product` 原实现以旧值为底 merge：发布 v2 写回 {净含量} 后回滚 v1（{净含量, 材质}），材质恢复 v1 值；但 v2 若曾确认 v1 没有的字段（如颜色），回滚后颜色仍显示 v2 值并指向 v2 来源——指针与商品口径漂移，违背「当前已发布版本是权威」。

# 负向生命周期出口：修订可换字节可放弃、失败资产可废弃

状态：第 28 刀短对齐产出（Owner 裁决，`docs/optimization-plan.md` P1 族三件一揽子）。映射 0006（版本不可变/修订语义）+ 0003（对象键不复用）+ 审计词条（回滚/发布之外的新动作种类）+ 0012（机洗失败就地重试不变），不新增中台对象、不改资产三态。

## 语义

- **修订换字节**：待人洗的修订版（含开修订继承版）接受「上传新字节」——写入新对象键（0003 键不复用）、**丢弃并清理旧修订对象键的字节**（孤儿清理，storage.delete 首个调用方）、对该版重跑机洗（与人洗字段共存：重跑保留已确认字段仅当字段集兼容，简单口径=重跑清空 extracted 但保留 confirmed 供继承——选「重跑后 extracted 重算、confirmed 保留」）。**线上已发布字节不动**（指针所指版本不可触碰）。
- **放弃修订**：存在未发布修订时，操作者可「放弃修订」——删该修订版（清字节、删版本行）、释放「同时最多一个修订」锁与回滚阻塞；audit 记 `discard_revision`（谁/何时/哪版）。放弃后可重新开修订或直接回滚。
- **废弃失败资产**：仅「已接入（机洗失败）**且从未有过已发布版本**」的资产可「废弃」——资产行标 `discarded`（列表过滤隐藏，不删除行）、清全部对象字节、audit 记 `discard_asset`。已发布过（含指针已回退）的资产不适用（历史权威不可抹）。
- **三态不破**：discarded 不是资产第四态（不进检索/治理队列，列表默认不可见；工程上是终态标记），词条「资产状态只有三态」的口径由「废弃=治理动作后的隐藏标记，不是状态」维持——CONTEXT 词条补一句。
- 审计动作枚举扩展：`discard_revision` / `discard_asset`（audit_log.action 是字符串列无约束；血缘 writebacks 集合不含二者）。

## 动机

两轮全链路走查实证的死胡同族：修订改不了正文（第 6 刀遗留）、修订锁死回滚无退路、GBK 文件机洗失败永远卡已接入——操作者的每个「开错了/传错了」都没有退路；孤儿字节清理自 storage.delete 落地以来零调用方，随本刀首次接线。

## 后果

- 三个新端点：`PUT /assets/{id}/versions/{no}/bytes`（修订版换字节）、`POST /assets/{id}/revisions/discard`、`POST /assets/{id}/discard`；治理台详情页三个对应按钮（按状态显隐）。
- Out：批量废弃、回收站/恢复、修订多版本并存（仍一锁一个）、已发布版本删除（永不）。

## 修订（审计刀 17，2026-09-16）：「已发布后废弃」的运维形态与全出口过滤

第 83 刀数据卫生首次造出「已发布后被废弃」的资产（262/269：手工 SQL 置
`discarded_at`，指针保留）——超出上文「已发布过不适用」的原语义，但它是**有真实
需求的运维形态**：已发布内容错了/重复了，治理面没有比隐藏更好的出口（历史权威
不可抹 ≠ 错误内容继续线上服务）。订正如下：

- **产品端点闸不变**：`_can_discard_asset` 仍拒绝已发布资产——单操作者语境下，
  已发布内容的错误走「开修订换正文」（治理正道，留版本链），只有运维级清理
  （重复/污染数据）才手工 SQL 越线。不为它开端点（开=鼓励把治理动作降级成
  删数据）。
- **越线是持久防御对象**：检索候选（`retrieve`/`oov_verdict` 语料快照/OOV count）、
  MCP 三读出口（search/get/export）、运营引用（`fetch_published_refs`，第 87 刀）、
  发布/换字节/重试闸（`_can_publish`/`_can_replace_version_bytes`/
  `retry_machine_wash`，第 84 刀）全部过滤或拒绝 `discarded_at` 非空——已发布后
  废弃的资产在**一切证据面**等同不存在。词条「已发布/检索索引/连接层」的口径
  相应补「未废弃」限定（见 CONTEXT 同日修订）。
- 字节处置：并发回流的孤儿补偿（审计刀 16）与机洗失败废弃会清未发布字节；
  已发布版本的**对象键不删**（历史版本的字节是审计锚，版本行保留）。
- 已知边界（记债）：`get_version_text` 对废弃资产的按版本读取无闸（读已删/
  保留字节），治理列表不可见使实际触发面接近零（审计刀 17 B-P2-11）。

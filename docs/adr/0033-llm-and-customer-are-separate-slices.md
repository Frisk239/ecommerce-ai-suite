# 厂商生成和顾客通道各自单独成刀；密钥只在本地 env

客服第一版是证据组装模板，尚未调模型。把 Chat API、顾客公开入口、限流塞进缺口刀或 MCP 刀，关刀路径会糊，密钥也容易写进仓库。裸的顾客 POST 会变成未计量推理入口。

接通厂商 Chat Completions 是独立刀：生成仍受 0018/0007 约束（无证据拒答、引用带版本、工具失败不拿检索顶）。环境变量为 `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`，只写被 gitignore 的 `.env`，不进文档、不进镜像。顾客对话通道（0021）也是独立刀：服务端签发会话令牌，按会话限流、每 IP 托底；不用操作者 cookie，不做无令牌狂刷。

# 销售考核：题库从已发布对话动态推导，单轮作答 LLM 三维打分，记录不是中台对象

状态：第 19 刀短对齐产出（Owner 裁决，audit-3 排期第 3 位）。映射 0027（考核打的是人不是客服引擎；与评测集区分）+ 0007（题源锚 asset_id+version_no）+ 0004（只抽已发布），无新中台对象、无新来源种类。

## 语义

- **题库动态推导，不落库**：题目=已发布（指针非空）dialogue 资产的 **confirmed `qa_pairs` 逐对展开**（每对一题：顾客问=题面，客服答=评分参照标准答案）；qa_pairs 弃权/空时兜底取**转写首行「顾客：」问句**（标准答案置空，评分只看 rubric 另两维）。每题锚 `{asset_id, version_no, pair_index|transcript}`（0007 引用口径：考核抽的是当时的版本）。
- **受训流程 v1=单轮**：AI 扮客以顾客语气出题（题面即开场）→ 受训销售（操作者）作答一次 → LLM 打分。多轮追问（原型 mock 的 AI_FOLLOWUP）留后续刀。
- **打分=LLM rubric，无降级**：三维口径沿用原型 RUBRIC——口径准确 40 / 证据与标准答案贴合 30 / 服务语气 30；LLM 返回 JSON `{accurate, evidence, tone, comment}`。**空 key 或 LLM 失败=该次 attempt 不落分**（记录标「未评分」，可重评；同素材生成「无降级」纪律——打分是考核的本体）。prompt 含：题面、标准答案（qa 对的 a）、受训者答案。
- **考核记录不是中台对象**：`coach_records` 表（考核模块自有）存题源锚/题面/受训者答案/三维分+评语/`model_name` 快照（扮演底座=评分时刻的 `settings.LLM_MODEL`，回放显示）/created_at。不能被检索、不能发布、不进治理台。
- **导出不建**：0027「考核不是资产」；「已发布可被考核抽取」词条由题库动态推导兑现（考核读已发布=消费面）；控制台导出基础设施不存在，不为考核单造。

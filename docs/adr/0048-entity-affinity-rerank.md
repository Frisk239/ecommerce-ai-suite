# ADR 0048：实体亲和重排（跨商品混淆的正解）

状态：随 `feat/rerank-79`（第 79 刀）提出；实验数字见 `docs/research/rag-eval-report.md` 第 79 刀节与 `scripts/eval/rerank_experiment.py`。

## 背景与病根

第 75 刀测量拒绝了候选来源权重（权威×1.25/评论×0.85，80 条期望 top-1 改善 0），当时结论：**病根在词法分本身**——`品牌：/净含量：/销售国家：` 等字段块在多个资产间**逐字相同或近同文**，字段名 bigram 对问句的分数完全一样（值部分不贡献交集），短块靠 sqrt 归一微弱胜出，并列时按 `(asset_id, chunk)` 稳定出榜。实测形态：问「钛钢保温杯的净含量」top3 全是 OFF 他品同文块（226/227）；「保温杯的材质」top1 被回流探针对话抢走。全局来源先验救不了——它不随问句变，会被词法大分差（0.8165 vs 0.4）吞掉。

## 决策

检索排序新增 **per-query 实体亲和乘数**（`services/retrieval.py`）：

```
final_score = lexical_score × stale_mult × (1 + AFFINITY_ALPHA × title_affinity)

title_affinity(q, asset) = Σ_{t ∈ 标题bigram ∩ q的terms} idf(t) / Σ_{t ∈ 标题bigram} idf(t)
idf(t) = log(1 + N / (1 + df(t)))    # df/N 按候选资产标题全集算（每次 retrieve 现算，~54 资产）
```

- **信号**：问句对候选资产**标题**的 IDF 加权 bigram 覆盖。正例问句几乎全部带商品名/标题前缀（「Erdbeeren的条码」「钛钢保温瓶的容量」）；跨资产共享 bigram（「规格（OFF）/评论/说明」）天然低 idf，专名天然高 idf——亲和由区分性词主导。
- **乘数**（`AFFINITY_ALPHA = 3.0`，实验矩阵定稿）：实验 α∈{0.5,1,2,3,4} 中 α=3 是甜点——α=4 时 positive 继续升但 confusion 回落（conf-013「物流怎么样」被标题明写「物流速度快」的他品评论抢走）。
- **落点**：`retrieve()` 内、打分后、排序前——引擎双通道 / MCP `search_published` / 缺口验证闸 / 大集评测**四个出口同语义**（ADR 0018 既有纪律）。
- **中性保证**：无实体问句（纯字段问/代词问/空标题资产）亲和恒 0，乘数 1，排序零漂移——这是「无提升不留」能被干净论证的前提。

## 已知取舍

- **标题是信号源**：回流资产的标题=会话首问（问句形态同源）、OFF 资产标题含商品名——都吃这个信号；**空标题资产**（演示库 4 条）亲和恒 0=中性，不因无标题被显式惩罚（只可能被点名资产相对超车）。
- **混淆组「字段名+怎么样」无实体问句**（conf-001「净含怎么样」）救不动——问句本身歧义，正确归宿是拒答/治理，不是检索猜心。本刀混淆@1 提升（60→73.3）来自 conf-001/002 类「字段词恰入标题」的间接命中，不是对这些问句的实体理解。
- **无向量路线不变**：ADR 0023 工程选型（纯词法）保留；本刀是词法内的重排层，不引入 embedding/模型服务（若将来上向量，本层语义仍独立成立）。
- `AFFINITY_ALPHA` 是可独立校准的常量（同 `STALE_MULTIPLIER` 先例）；改它必须复跑 `run_eval.py` 刷新基线。

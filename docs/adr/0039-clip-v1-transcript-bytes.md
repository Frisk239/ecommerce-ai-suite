# 切片 v1：候选种子 mock、登记字节=带时间码转写文本、只登记视频资产不造任务

状态：第 18 刀短对齐产出（Owner 裁决，audit-3 排期第 2 位）。映射 0014（候选不是资产/拣选才登记）+ 0015（只登记资产不暗插任务/素材中心汇入视图）+ 0025（clip_pick 来源已锁）+ UX-NOTES §四（切片暗插任务需产品先写明——工程按 0015 只登记），无新中台对象、无新来源种类。

## 语义

- **切片候选 v1 = 种子 mock**：`clip_candidates` 表（素材中心侧自有，非中台对象）带时间码/转写/商品标签/`source_video_label`（源录像的名称字符串——mock 店铺语境，不存源录像字节，真实 ASR/ffmpeg 留部署刀）。候选生成不做自动切出（UX-NOTES「mock 大脑不冻结」）。
- **登记字节 = 带时间码头的转写文本**：拣选时写对象存储的字节是 `[HH:MM:SS-HH:MM:SS] 转写…` 形式的文本（kind=video）——不是 mp4。理由：工程无视频切出基础设施，原型冻结口径即「登记内容=转写」；对象键前缀 `clips/`。真视频字节与切出是部署刀的事，本 ADR 记录该边界。
- **机洗对 video**：转写文本 UTF-8 可解析；字段集为空（口语转写跑规格正则会误抽，不挂商品字段语义）→ 弃权推进待人洗，与 dialogue 无 QA 时同形。
- **拣选动作**：批量勾选→一次登记 N 条（每候选一资产：kind=video、source_kind=clip_pick 服务端定值、挂候选的商品标签、title=转写截断）；候选行记 `registered_asset_id` 回执锚，**单向状态机**（已登记不可再拣选，409）。
- **切片汇入视图**：素材中心页加页签「切片汇入」= 来源=切片拣选且种类=视频的**已登记资产**列表（0015：视图不是二次登记，运营只引用已发布）。
- **侧栏**：「直播切片」入口（group:null 跟随素材中心先例）。

## 动机

审计刀 3 功能缺口：素材/切片/考核三模块缺席；素材（第 17 刀）后切片是内容闭环第二段——直播口语内容经拣选进入中台成为可检索证据。原型 Clips 页交互状态机已冻结（未拣选→已选→拣选登记→已登记单向）。

## 后果

- 迁移 0010 `clip_candidates` + 种子候选；`make_object_key` 加 clips 前缀；KIND_LABELS 补 video。
- Out：自动切出候选、真视频字节、ASR、切片重切/撤销、批量上限调参、源录像管理页。

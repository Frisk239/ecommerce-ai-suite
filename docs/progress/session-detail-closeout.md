# 第 57 刀 closeout：会话详情补齐站点/访客/评分（`feat/session-detail-57`）

日期：2026-09-11。依据：审计刀 11 的建议 ③（「会话详情渲染站点/评分/访客——CSAT 与 widget 闭环的最后一环」）+ 审计刀 11 P2-1。**无新表无迁移**。

## 交付

| 件 | 交付 |
| --- | --- |
| 契约 | `SessionDetail` 补 `visitor_id` 与 `rating`（`host_origin` 审计刀 11 已补）——**详情与列表行同源**，深链 `?session=N` 进来能看到同样的上下文；`rating` 一次 `select score` 取（一会话一评，未评 None） |
| 界面 | 会话详情头部在「会话 #N / 状态 / 开始时间」之后显示 **站点 / 访客 / ★ 评分** 三枚 chip（与左侧列表行同形、同文案）；未评分为 `null` 时不渲染（不显示「★ undefined」） |

## 验收（实测）

1. **接口**：`GET /api/service/sessions/102` → `{host_origin: 'http://localhost:5173', visitor_id: 'bc1988d4-…', rating: None}`（widget 建的会话）；`GET /api/service/sessions/84` → `{host_origin: None, visitor_id: None, rating: 4}`（独立访问 + 已评分）——与列表行逐字段一致。
2. **界面（真浏览器）**：深链 `/service?session=102` → 头部「会话 #102 · 未开始 · 开始于 … · **站点 localhost:5173** · **访客 bc1988d4**」；`/service?session=84` → 头部「… · **★ 4**」。
3. **未评分不渲染**：`rating is None` 时不出现星级 chip（对照 #102）。
4. **门禁**：集成 **941 → 943 passed / 0 failed / 0 skipped**（详情三字段断言 + 评分详情用例）；ruff 全过；前端 build 绿、lint 7/0。

## 诚实披露

- **详情不带消息数**（`message_count` 仍只在列表行）：详情页用「已加载消息数」分叉空会话文案（第 42 刀起如此），本刀没动——两条口径并存是既有事实，不属本刀范围。改它要动 `SessionDetail` 再算一次 count，收益（一个徽章）不值。
- 站点/访客仍是**前端自报 + 白名单**（第 45b/54 刀的既有边界，README 局限段同述）；本刀只是把它们渲染出来，不提高其可信度。
- 评分**不可改**（一会话一评）——详情的 ★ 只读，与总览 CSAT 段一致。
- 端到端证据是**本会话实测输出**（接口 JSON + 界面文本回显），未落成截图文件。

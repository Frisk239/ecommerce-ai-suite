# UX-A1 刀规格：工作台可扫读（前端，平行工作流，不占刀号）

日期：2026-09-10。分支 `feat/ux-a-workbench`（基于 main `6453b8d`）。依据：`docs/ui-ux-plan.md` §四 UX-A + §九 S3/S4。本刀只做**前端**；目录回答模板（UX-A.5）拆到下一刀 `feat/ux-a-catalog-listing`（后端 + 评测纪律）。

## 为什么要做

打开资产/商品/客服，第一眼是 CI 冒烟垃圾（16 条 `mcp-smoke`/`evidence probe`）和百科灌入货（商品 115 件里仅 3 件已定价），演示主路径（保温杯/瓶装水/政策）找不到。这一包把「工作队列」变成默认视角，并给列表加搜索、给商品排序、给空会话降噪。

## 裁决（Owner 已定，实现按此）

1. **工作队列谓词 = `source_kind === 'mcp_registered'` 且标题匹配 `/^(mcp-smoke|evidence probe)/i`**（组合，不用「凡 mcp_registered 即排除」——连接层 MCP 登记是正式功能，不能一律隐藏）。
2. **总览与列表同口径**：总览页的待人洗/已发布计数必须用同一谓词，否则两处数字不符（§二点十 冻结原则）。
3. **演示库不删**（`docs/ui-ux-plan.md` §四 UX-A Out 明写「不删库」；且 `/discard` 仅限 ingested、`/revisions/discard` 对「从未发布的 v1」409，API 清不掉，裸 SQL 属破坏性操作留 Owner 裁决）。过滤解症状；一次性清理 SQL 记入 closeout 备查。
4. **搜索用局部 state**（不进 URL），匹配标题（不区分大小写）+ `String(id)` + `A-0000` 形态的 ID。
5. **商品「有写回规格」= `spec_schema` 与 `spec_values` 求交非空**（`Object.keys(spec_schema).some(k => spec_values[k])`）——防类目切换残留旧键。
6. **空会话（`message_count === 0` 的 active）**：徽章改「未开始」（中性，非「进行中」蓝），列表排序沉到有消息会话之后；默认选中改为「最新一条有消息的会话」，无则回退第一条。**不做**「自动关闭」（需后端新行为，超范围）。
7. **搜索跨状态**：搜索的语义是「找这条资产」，有查询词时跳过状态 tab、在当前视图（工作队列/全部登记）内全状态搜——否则默认「待人洗」下搜已发布资产（如 `A-0029`）得 0 行，验收 4 不成立。代价是搜索态下 tab 计数与结果数不同步，用文案「N 条匹配 · 搜索覆盖全部状态」缓解。
8. **范围开关文案 = 「工作队列 / 全部登记」**（避免与状态 tab 的「全部」同词双义）；知识缺口 tab 下不显示范围开关（该 tab 数据走独立端点、不过工作队列）。

## Must

1. **资产列表默认 tab = 待人洗**（无 `?status=` 时）。点「全部」必须写显式 `?status=全部`（不能清空 URL，否则回落待人洗点不动）。`setSearchParams` 改函数式 updater，保留其他参数。
2. **「工作队列 / 全部」开关**（默认工作队列），URL `?view=work|all`；`view=work` 时排除谓词命中的行；过滤必须**同时**作用于 tab 计数（徽章）与列表、以及**总览页计数**。
3. **资产列表搜索**（标题 / ID），样式照 `components/ProductSelect.tsx:67-110`（`Magnifier` 图标 + `input w-full pl-8 pr-8` + 清空按钮）。
4. **商品页排序 + 折叠**：已定价、有写回规格的在前（稳定按 id 兜底）；其余折进「其余商品 N」可展开区；删掉每张卡重复的「写回只在发布时发生」脚注（`ProductsPage.tsx:394-396`）。
5. **客服会话列表空会话降噪**：见裁决 6。

## Out

- 后端零改动（本刀）；不删库；不做空会话自动关闭；不做 390 窄屏卡片化（属 UX-G）；不碰发送钮/token（属 UX-E）。

## 验收

1. 裸进 `/platform/assets` → 默认「待人洗」，且**看不到** `mcp-smoke`/`evidence probe`。
2. 切「全部」→ URL 变 `?status=全部`，能看到全部；再切回待人洗不丢 `view`。
3. 工作队列下待人洗计数 = 190（206 − 16）；总览页待人洗数字与之一致。
4. 搜索 `保温杯` / `A-0029` / `29` 都能命中（含已发布资产，即搜索跨状态）；清空恢复。
5. 商品页首屏是保温杯/瓶装水等已定价商品；未定价的折进「其余商品 N」并可展开。
6. 客服列表不再出现「进行中 ·（还没有提问）」；0 消息显示「未开始」并沉底；点开默认落在有消息的会话。
7. `npm run build` + `npm run lint` 绿（告警数与 main 基线一致）；后端零改动。

## 坑

- `setTab` 的 `setSearchParams({...})` 是**整体替换**，加 `view` 后 tab 切换会抹掉 view——必须函数式更新。
- 计数有三处同源逻辑（列表 counts、列表 stat card、总览 counts），共用同一谓词/工具函数，禁止复制。
- 搜索要能命中 NULL 标题资产（用 ID 搜），`title ?? '未命名资产'` 兜底后同样可搜。
- 排序必须稳定（同分按 id），否则每次渲染跳位。

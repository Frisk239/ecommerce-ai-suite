# 第 71 刀 intake：评分可改（Owner 裁决：覆盖式留最新）

上一刀：审计刀 14（PR #103）。Owner 裁决（2026-09-11 完善路线批）：**评分可改 = 允许**
（顾客常在后续互动后想改分）；另两项裁决维持（分币种报价维持拒答、默认视角维持现状）。

## 现状（第 48 刀）

一会话一评、已评 409、前端评过即收（致谢行）；model 注释明写「不做改评（v1）」。

## 设计

- **覆盖式留最新**：`session_ratings` 一行仍唯一（唯一约束不动），改评是 UPDATE
  （score/comment 整体覆盖）；新增 `updated_at`（迁移 0029，NULL=首评未改）。
  comment 不带即清空——前端提交时回填当前留言，故点星不会意外清留言。
- 前端：评过**不再折叠**——星星回显当前分（hover 预览覆盖）、留言框回填、
  点星即再提交；状态行「已提交 N 星（，已更新），可随时修改」。
- `record_csat_rating` 计**每次提交**（含改评）——指标口径=评分事件数，CSAT
  均分/分布读行数据（始终最新值）。

## 明确不做

- 不做评分历史（只留最新——审计留痕不进 CSAT 面，要追溯看 audit 日志若有）。
- 不做「确认弹窗」（点星即改，误点再点即改回——与点星即提交同交互密度）。

- **操作者面两端点**：`GET /api/assets/{id}/media`（服务端取最新版——列表缩略图用）与 `GET /api/assets/{id}/versions/{n}/media`（详情预览用，版本号进 URL 是 `<img>/<video>` src 的形态约束）。**版本语义与顾客面相反**：治理面未发布版本可读（W8 第一诉求=人洗对照原图）；已废弃 404、非媒体 404、对象缺失 409 带键（治理面如实说，不做存在性隐藏）。鉴权=操作者 cookie（同源 img/video 自动携带）。

### B（PR #167）：W9+W10 检索

- **`src/search.ts`**：`splitTerms` + `matchesAllTerms`（空格分词 AND——单词=原子串行为不变，多词=每词命中任一字段）。**不放宽成 OR**（命中集炸开）；「退货」搜不到《退换货政策》的出路是在提示里教「退 货」两词分别命中（连续子串限制如实说）。真分词/拼音留 Out。

- **资产页**：同一口径替换原单子串过滤；placeholder 与空态提示更新。

### C（PR #168）：W11+W13+W14 切片页三连

- **W11 帧缩略**：`GET /api/clips/candidates/{id}/frame`——timecode_start 处抽真帧（`extract_frame_jpeg` 复用，≤480px 与洗帧同规格）。进程内 LRU（键=(recording_id, timecode_start)——两要素不可变，改绑自然换键，永不陈旧）。未绑录像 409（demo 候选无字节，占位仍是诚实设计 0039）；时间码坏 422；字节缺失 404；抽帧失败 422。`parse_timecode_seconds` 公共别名（路由不 import 私有名，切段/抽帧解析口径不可能漂移）。前端 `CandidateFrame`：onError 回退占位框；`?r=recordingId` 换浏览器缓存键（服务端不读）。
- **W13 筛选**：状态 seg（全部/待拣/已登记带计数）+ 源录像 select（含「未绑定」项）+ 关键词搜索（多词 AND 同 B）；筛选空态带一键清除。
- **W14 详情抽屉**：卡片头「详情」钮（stopPropagation 不抢勾选手势）→ 大帧 + 状态/归属/时间码/转写来源/绑定源录像 + 转写全文 + 登记锚外链。

## 设计裁决（随刀）

- **顾客面 404 / 操作者面 409** 的存在性口径差异是有意的：顾客面无凭证不该探测、未发布不该泄漏；治理面对象键本来就可见（版本列表），缺失如实说带键。
- **帧缓存键含 recording_id**：候选时间码不可编辑、录像字节不可覆写，两要素不可变即为缓存安全边界；不设 TTL 不设失效钩子（改绑=换键，天然失效）。
- **详情入口用独立小钮而非「预览框可点」**：卡片整体已是勾选选区，嵌套可点区域会制造误触；小钮 + stopPropagation 是零歧义形态。

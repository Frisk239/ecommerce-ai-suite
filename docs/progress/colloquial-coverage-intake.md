# 第 65 刀 intake：问货/问价口语覆盖收口（卖完卖光 / 咋卖 / 贵吗）

上一刀：第 64 刀导入货折叠语义对齐（PR #94）。本刀收第 62 刀 Spec 轴评审留下的
「难以定性」清单里**属于自然问法、却被拒答**的那部分。

## 开刀前实测（直调工具层 + 浏览器）

| 问句 | 层 | 开刀前 | 应然 |
| --- | --- | --- | --- |
| 书都卖完了吗 / 杯子卖光了吗 / 平板卖完了还有吗 | 问货 | 拒答 | 类目库存聚合 |
| 手机咋卖 / 彩电咋买 | 问价意图 | 拒答（意图词表只有「怎么卖」，不认「咋」） | 类目价 |
| 手机贵吗 / 笔记本电脑贵吗 | 问价意图 | 拒答（意图词表只有「贵不贵」） | 类目价 |
| 笔记本到货了没 / 什么时候有货 | 问货 | 拒答 | **照旧拒答**（问的是到货**时间**，库存工具答不了，回落留缺口是正确归宿） |

## 本刀范围（小刀）

1. `STOCK_KEYWORD_PATTERN`（**路由词表**）补 `卖完|卖光`；`_STOCK_FILLER_WORDS`
   （纯度虚词表）补原子词 `卖完/卖光`。**两层都要**——浏览器验收抓的层间缝：
   只补虚词表时「书都卖完了吗」（无「有」字，`有.{0,12}吗` 不命中）根本进不了
   库存工具，直调 `query_stock` 的单测测的是工具层，测不到路由层。
2. 问价意图词表 `PRICE_RE` 补 `咋卖|咋买` 与裸 `贵`（**排在「贵不贵」后面**，
   长词先匹配，否则「贵不贵」被「贵」吃掉剩「不」）；纯度虚词表 `_PRICE_RE`
   同步补裸 `贵`（意图层认、纯度层剔不掉 = 死意图路径，第 62 刀的教训）。
3. 负例钉子：别名词当修饰语（电脑桌贵吗/二手手机贵吗/手机膜咋卖/手机膜卖完了吗）、
   求助形态（书卖完了怎么办）、政策问（退货运费贵吗——政策闸仍在意图层之前）。

## 明确不做

- 不收「到货」：到货了吗/到货了没 问的是时间，照旧回落拒答留缺口（正确归宿）。
- 不动检索/生成路径（评测尺覆盖面外，照例复核零漂移即可）。

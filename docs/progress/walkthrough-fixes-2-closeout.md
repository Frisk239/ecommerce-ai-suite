## 验收（内置浏览器实测）

- **可达性**：题库行实测 `role="button"`/`tabindex="0"`；对该行按 **Enter 打开「销售考核作答」抽屉** ✓；「开始作答」按钮可点（弹层标题、题面、题源链接、标准答案开关、作答框、取消/提交评分俱全）。
- **中文优先**：题库首行 =「保温杯的净含量是多少？」（英文题沉底）✓。
- **标题溢出（视觉）**：截图对照——长英文/中文标题现在带省略号，`种类/来源/状态/所挂商品` 列干净不再被压 ✓；DOM 量测考核页 6 格 `overflow=0`、`text-overflow=ellipsis` ✓。
- **首帧「—」**：代码路径 `state.phase !== 'ok' ? '—'`；loading 窗口（localhost 往返 <50ms）在工具边界内不可稳定捕获，**如实记为代码级验证**。
- 前端 `npm run lint` 7/0（基线）、`npm run build` 绿；后端零改动（集成 1161 基线不动）。

## 诚实披露

- **首帧「—」无截图证据**：本地加载太快，抓不到 loading 帧；验证靠代码路径与同页缺口子 tab 的既有「—」口径。
- 标题 `truncate` 在**极长标题**下会把行尾的「过期未验证」徽章挤出可见区（徽章是 stale 才出现，罕见）——取舍：宁可截断文字也不让它压邻列。
- 考核行加 `role="button"` 后，行与行内「开始作答」按钮形成**嵌套可点**（行 Enter=打开，按钮点击=打开，行为一致，非冲突）。
- 走查方案里 P2-2（会话搜索）/P2-4（评分态）与 §五 的 77/78 刀序仍待排。

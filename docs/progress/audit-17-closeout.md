## 记债（本刀新立，供下一刀排期）

1. **免责句当回答 + auto-close 以 kind 判**（C-P1-1 子发现，最值得下一刀）：「未覆盖保修信息」「未给出净含量数值」两种措辞挂 kind=answer + 引用——58 刀 `strip_coverage_disclaimers` 的词表没收这两形态；且引擎 answer 路径自动关同问 open 缺口（`resolve_gap_answered_by_catalog`）以 kind 为判据，免责式回答会把知识仍缺的缺口「答非所答」地关掉。G-0053/G-0064/G-0025 保留 open 即此因。

## 认知订正（记录）

1. **语义闸的「闸后追问」**：零命中绕闸问题（B-P1-1）第一反应是「补闸」，但补闸的误判面（知识问句被判成不在库）比漏检面贵——「闸只装一条路径」的教训不能机械推广到「闸该装到每条路径」，先问漏检与误判哪个贵（刀 12 口径的再适用）。
2. **文档债的复利**：82-86 五刀语义全住在 closeout 和代码注释里，ADR/词条层零跟进——三轴审计时 A 轴一半 P1 是这个。语义变化必 ADR 的纪律（roadmap 排期原则）对「判定链类」改动同样适用，不只对工具语义。
3. **module 级共享 app 的 MCP 测试**：session manager.run() 每实例一次，第二个进 lifespan 的用例会静默降级「/mcp 不可用」而 HTTP 断言照常绿——新建 app 实例（同库同存储根）是文件内既有先例，新用例必须照抄。

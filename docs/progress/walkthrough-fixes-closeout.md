## 验收（浏览器实测，非目测）

- 商品 / 素材任务 / 考核作答 / 登记 / 缺口五个抽屉 Esc 均可关（此前商品/素材/考核三个关不掉）；`ConfirmDialog` Esc 仍可取消。
- 商品抽屉：无改动 Esc 直接关；改价后 Esc **弹确认**（「放弃未保存的改动？…商品保持原值」）；点遮罩同样弹确认；点「放弃改动」→ 关闭且**库里单价未变**（300 分），无静默保存；把 129 改成 `129.00` 视为等价 → **不弹确认**（误报已修）。
- 运营：点「清空画布」→ 画布回到空态并提示「服务端记录仍在（刷新会重新显示最近一条）」，无任何删除 API 调用。
- 缺口：徽标 7 / 待补 7 行、已解决 2 行；切分段行数随之变化；抽屉只剩一条提示。
- 控制台：favicon 404 消失（登录前仅剩 2 条预期的 `/api/auth/me` 401）。
- `npm run build` 绿；lint **7 warnings / 0 errors** 与 main 基线逐数一致；无新依赖、无新色值（favicon 取既有 token）。

## 两轴评审与处置

两轴独立子代理均判**可合并**（无 P0）。已采纳：

- **P1 提交门禁不齐**：`RegisterAssetDrawer` 的 Esc 受提交态约束、遮罩与 X 却不受 → 提交中点遮罩可关（可能让人误判登记结果）。已让遮罩与 X 同门禁；`ConfirmDialog` 的遮罩同样补 `busy` 门禁（此前 busy 中 Esc 无效但点遮罩可取消）。
- **P2 新建态 `dirty` 漏类目** → 选了类目又关掉等于白选，已把类目计入。
- **P2 单价字符串比较误报** → 改按「分」比较（见上）。
- **P2 清空后空态标题仍是「还没有编排任务」** → 改为「画布已清空」。
- **P2 缺口提示语义重复**（`gapFillNote` 已含「发布后自动解决」）→ 去掉重复的收尾句。

记债（P2，未改）：`useEscapeClose` 的 `onClose` 每渲染新建会使 effect 重挂（功能无碍，建议后续用 ref 稳定）；缺口分段 tablist 缺 `aria-controls`/`tabpanel` 与方向键切换（与全仓既有 tablist 同一水准，未单独拔高）。

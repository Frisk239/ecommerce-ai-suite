被错杀成拒答（观点标记表无法枚举形容词）。

## 设计的两次裁决（初版被评审证伪后反转）

- **初版（已废）**：服务词 + **事实问尾白名单**（了吗/到哪/多少/政策…）+ 无观点
  标记才拦——把「拦」变成需要枚举事实问的**开集**。评审证伪：「退货运费谁承担」
  「查物流」「发货地是哪里」等未枚举同义事实问全部漏放，引用无关评论作答
  （「谁承担」下衣服评论 0.894 夺冠）——66 刀 P0 的同义复现，**错误答案**。
- **终版**：**保持 66 刀默认拦**（服务词 + 无观点标记），把错杀问题改由**扩观点尾
  白名单**解决（好吗/专业吗/严实吗/结实吗/及时吗/顺利吗/麻烦吗/暴力吗/给力吗/
  耐心吗/墨迹吗/爽快吗/稳吗/满意吗…品质形容词+吗 的实测形态）。两害相权：
  漏枚举观点尾 = 诚实拒答留缺口（便宜、治理台可见）；漏枚举事实尾 = 错误答案（贵）。

## 明确不做

- 不追形容词穷举（开集；漏的落缺口走治理）。
- 不动引擎金标与检索金标（到货了吗/物流怎么样/客服态度好吗 三态各自钉住）。

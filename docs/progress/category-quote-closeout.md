# 第 52 刀 closeout：按类目问价（`feat/category-quote-52`）

日期：2026-09-11。依据：审计刀 10 的 **P1-2 / 下一刀建议 ①**——列举刚说「共 115 件，均已定价」，紧接着问「笔记本电脑多少钱？」却**拒答 + 落缺口**。**无新表无迁移**；ADR 0045 追加「§二修订之二」。

## 交付

| 件 | 交付 |
| --- | --- |
| 类目报价 | `catalog_tools._category_quote` + `render_category_quote`：报价意图 + 命中**类目名** + 问句主体就是「类目 + 问价」（**纯度闸同款**）→ 答「类目共 N 件，其中已定价 M 件，均为 X 元 / 价格 X–Y 元（另有 K 件未定价）；问具体型号给你准确价」。类目价是**商品行现算的聚合事实**，不新增「类目基准价」字段 |
| 判定顺序 | 先商品名（纯问价）→ **商品名命中但纯度不足时仍试类目路径**（商品「笔记本 A」与类目「笔记本电脑」可能同时命中）→ 两条都不成立才算实质问句，交回 RAG |
| 两条路径共用 | 类目判定同样放在共用的 `_quote_answer` 里：空命中回落与「有命中也要报价」两条入口都能按类目答（审计刀 10 P0 的教训：**新判定不能只加在一条路径上**） |
| ADR | 0045 追加「§二修订之二（第 52 刀）：按类目问价」——写清形态、聚合口径、判定顺序与 miss 归宿 |

## 验收（真栈实测）

- `笔记本电脑多少钱？` → catalog 工具式：「**笔记本电脑共 34 件，其中已定价 34 件，均为 4999元**；问具体型号给你准确价。」
- `食品多少钱？` → 「食品共 21 件，其中已定价 21 件，均为 3元；…」
- **不抢**：`笔记本电脑刻字怎么收费？` → 不走报价（交回 RAG）；`无人机多少钱？`（类目不存在）→ 照旧拒答 + 落缺口（去补=上新）。
- 单元/集成钉子：区间与件数模板、同价「均为」、纯度闸（服务问不被抢）、无价类目与未知类目 miss、真引擎端到端（种子「食品」类目 → 答类目价、citations 恒空）。
- 门禁：集成 **921 → 926 passed / 0 failed / 0 skipped**；ruff 全过；前端未改（build/lint 回归确认 7/0）；大集评测不经目录回落分支（第 41/50 刀同口径，零漂移）。

## 诚实披露

- **订正（审计刀 11）**：原写「演示数据暂时看不到区间」**不成立**——演示库「器皿」类目就有两个价（种子钛钢保温杯 12900 + 手建不锈钢保温壶 9900），实测 `器皿多少钱？` → 「价格 99元–129元」；其余 8 个类目确实是单一基准价、答「均为 X 元」。所以区间形态**现在就能在演示里看到**（问「器皿多少钱」）。
- **类目名匹配是「问句里出现该类目名」**（不是模糊匹配）：说「笔记本多少钱」而类目叫「笔记本电脑」时**不命中**——`match_product` 的 LCS 口径只用在商品名上。这条与「按类目问价」的自然说法有差，记为债（要支持得给类目名做同义/别名，属另一刀）。
- 类目价是**聚合事实的现算值**，不落库、不进引用（citations 恒空、kind=answer、tool 记录 `{name: catalog, arg: 类目}`）；商品行仍不是中台对象（0002）。
- 端到端证据是**本会话实测输出**（问句与答案原文），未落成截图文件。

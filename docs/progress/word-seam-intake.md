# 第 67 刀 intake：56 刀词面邻缝收口（咋样卖/咋价/还有么/指示词）

上一刀：第 66 刀评论证据适用域（PR #97）。本刀收第 62/65 刀评审与审计刀 13 移交的
**词面邻缝**存量——「打磨到审计清零」路线上的最后一个小刀。

## 开刀前实测（全部拒答/不派发）

| 问句 | 层 | 缝 |
| --- | --- | --- |
| 彩电咋样卖 / 手机咋样买 | 问价意图 | 意图表有咋卖/咋买没收**咋样卖/咋样买**（65 刀）；咋样单独不是价格词（评价问） |
| 手机咋价 | 问价意图 | 与啥价对称，咋价不在表 |
| 这手机啥价 / 那个手机咋卖 / 这台笔记本电脑多少钱 | 纯度 | 残字 这/个/台（价格虚词只收了这个/这款复合词，库存侧 65 刀已收裸字） |
| 书还有么 / 手机还有呢 | 库存路由 | `有.{0,12}吗` 只认吗——纯度层能答、路由不派（56 刀邻缝，审计刀 13 移交） |

## 本刀范围（小刀）

1. 意图 `PRICE_RE` += `咋样卖|咋样买|咋价`（**只收复合词**——咋样单独是评价问，负例钉住）。
2. 纯度 `_PRICE_RE` += 裸 `这|那|个|台`（与库存侧 65 刀对齐；修饰语靠残字挡）。
3. 路由 `STOCK_KEYWORD_PATTERN`：`吗` → `[吗么呢]`（路由器语义下放宽安全——查不到照旧回落；
   「到货了么」无「有」仍不派，65 刀的时间问句口径不变）。

## 明确不做

- 不动检索/证据闸（66 刀刚交付）；不动评测金标。

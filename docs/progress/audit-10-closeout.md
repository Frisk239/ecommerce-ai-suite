## 实修

### P0

1. **报价纯度闸只装在两条报价路径中的一条**（A-P0-1，live 复现）：`try_catalog_answer` 的空命中报价分支**没有**纯度闸，闸只在 `try_price_answer`（有命中那条）。实测（演示栈、该问句检索 0 命中）：`try_catalog_answer(db, "家具送货安装怎么收费？", [])` → 「WANDS 家具（演示）（家具）**售价 899元**」——服务问句被答成商品价。第 50 刀的验收之所以没抓到，是因为「保温杯刻字怎么收费」**恰好有 5 条命中**才落到被闸的那条路。修法：三道判定（命中商品名 + 有价 + 纯度）全部收敛到**共用的** `_quote_answer`。**复核**：同一问句现在 `no-tool`（交回 RAG），纯问价仍答 129元。
2. **演示库两份已发布退货政策打架**（C-P0-1）：asset 6（「签收后7天内可申请退货」）与 asset 13 v3（「退货政策：15天无理由退货（升级版）」）都已发布 → 顾客问「退货政策是什么？」答出「已发布证据中退货政策**存在两个口径**」。这是 2026-09-09 一次修订演示留下的、发布后未对齐的存量数据。修法：**走平台自己的治理路径**对齐（asset 13 开修订 → 换正文为 7 天口径 → 发布 v4；v3 成为历史，不直接改库）。**复核**：同问句现在只答「签收后7天内可申请退货。[1][2]」（citations `13/v4` + `6/v1`），不再提两个口径。

### P1

3. **纯度闸要求「商品全名字串」，部分名问价被静默挡回 RAG**（B-P1-1）：`match_product` 按 LCS≥2 命中，闸却用 `question.replace(全名, "")` —— 「保温杯多少钱」对商品「钛钢保温杯」残留「保温杯」→ 不回落；同一句问话答不答取决于检索有没有命中（典型静默面）。修法：新增 `stock_tools.lcs_fragment`（与 `_lcs_len` 同源的 DP），闸剔除**命中的公共子串**。**复核**：「保温杯多少钱？」→ catalog 129元。**钉测**：部分名纯度纯函数 + 端到端。
4. **ADR 0045 修订段漏记纯度闸、且把「规格问」的拦截错记给四道闸**（A-P1-1）：照 ADR 重写会重开 P0-1。修法：ADR 补「报价还要过纯度闸（`price_residual`），且必须装在两条报价路径共用处」，并订正拦截归属。
5. **ADR 0047 称「多源仍留 Out」，但 bind 已让「按候选分别绑不同录像」在 API 层可达**（A-P1-2）：不设闸、如实记（产品面/UI 仍单源，默认全部待拣一起改）；ADR 加「多源口径订正」段，并写明要严格单源就得在 bind 端点加闸（属另一刀的产品决定）。
6. **导入脚本不写来源，重置演示库/新环境复现不出 README 承诺**（B-P1-2）：`fetch_wikidata_products.py` / `load_openfoodfacts.py` / `load_wands_clips.py` 插 `products` 时补 `source_kind="open_dataset"`（演示价仍由迁移/管理台回填，README 已注明）。
7. **来源筛选会变成「隐身过滤器」，空态文案说反话**（C-P1-1）：点 chip 再切 tab 时，该来源在新 tab 计数为 0 → 没有任何 chip 高亮、表格空、空态还说「新登记的内容会先进已接入」。修法：选中的来源**即使在当前 tab 为 0 条也渲染该 chip（标 0）**；空态区分「筛选所致」与「真无数据」，并给「清除来源筛选」按钮。
8. **`?source=` 不校验取值**（C-P1-1 同源）：拼错/陈旧来源会得到一个名叫「typo」的 chip + 说不清为什么空的屏幕。修法：前端用 labels 映射判「是不是已知来源词」，未知值当作未筛选。

## 记债（未修，逐条给理由）

- **按类目问价仍答不出**（C-P1-2）：列举刚说「共 115 件，均已定价」，紧接着问「笔记本电脑多少钱？」却拒答 + 落缺口——`match_product` 只认商品名，类目名不是商品名（9 个类目全中招）。这需要「类目→商品」的报价形态（范围价或列该类目已定价若干件），属**新能力**而非本刀缺陷；列为下一刀首选。
- **四份数据集在产品面只做到「评论 vs 其余三份」**（C-P1-3）：Wikidata/OFF/WANDS 在界面上都叫「开放数据集」，无法逐个区分（词表就是两值）。要逐个可见得再扩来源词或加数据源字段——属产品决定。
- `.slice-test.mp4`（5 秒）仍在录像下拉里，可被绑上——但候选时间码全超出其时长，每次拣选 422（已有放回逻辑兜底）。「绑定时校验时长是否覆盖时间码」留后续。
- widget 不落宿主 origin（审计刀 8 起）；CSAT 低分无深链、不可改评（第 48 刀起）；工作队列默认视角是否改（Owner 观感裁决）。
- 迁移 0026 的判据是「形态」而非身份（手建同形态行会被打标）；`DEMO_PRICES` 在迁移与 seed 两处字面量（无相等性测试）；砍掉 20 条上限的分页（录像列表）。
- 51 的服务端 `?source_kind=` 当前无产品消费者（控制台走客户端过滤）。

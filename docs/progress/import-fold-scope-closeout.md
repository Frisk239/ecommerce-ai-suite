## 诚实披露

- **「全部」tab 的主行变长了**（已发布导入行进主行）：这是规则的自然结果——「全部」
  不再藏线上证据。若 Owner 更想要「全部也折」，规则可以再收（本刀选择语义一致性：
  折叠=待办噪声）。
- 折叠计数从「全部导入」变为「未发布导入」——第 59 刀 closeout 里的「默认 15 行 ↔
  展开 195 行」是**当时**的数（待人洗 tab 内），本刀在该 tab 行为不变（180 为当前
  演示库的实时数，随治理动作自然变化）。
- 前端无单测框架（与历刀同口径），验收靠 build/lint + 浏览器点穿；谓词逻辑极薄
  （两个既有谓词的合取）。

## 评审处置（两轴独立评审：均无 P0/P1）

- Standards 轴 P2：intake 初稿谓词名写 `isFoldedSource`、实现为 `isFoldedImport`——
  intake 已补订正说明。**预存观察移交审计刀 13**：`ConnectPage.tsx:98` 与
  `AssetsListPage.tsx:272`（fillGap）手抄 `current_published_version_no !== null`
  即 `isPublished` 的副本，违反 workQueue「禁止手抄谓词」的字面要求（HEAD 已存在，
  非本刀引入、亦非导入/发布组合，本刀不扩面）。
- Spec 轴 P2×2（行为披露）：①**搜索同时命中已发布与未发布导入行**时，自动展开
  不再触发（主行非空）——未发布命中项收进折叠头。这是单一规则的自然结果且
  intake 明文接受（「屏幕非空即无『像没找到』问题」）；若日后收到「搜索要看见
  全部命中」的反馈，收紧点是「有查询词时也自动展开」，属下一刀裁量。②折叠头
  副注「已发布的导入行在上方主行」在待人洗/已接入 tab（无搜索）下是空真——无害，
  悬停解释仍准确。
- Spec 轴另确证（代码级不变量）：后端一切可达状态下 `status=='ingested' ⟹ 线上
  指针为 null`（指针只在发布/回滚事务里与 `status='published'` 成对写入；换正文
  机洗失败有「已发布不降级」守卫）——故已接入/待人洗两 tab 新旧谓词**严格等价**，
  行为逐位不变，与演示库数据无关。

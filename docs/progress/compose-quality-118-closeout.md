# 第 118 刀 closeout：成片质量升级（W18 广告脚本结构 + Ken Burns + 垫乐 + 水印取消）

日期：2026-09-18。分支 `feat/compose-quality-118`。来源：第六站 Owner 验收反馈（保温杯成片=「几个字幕+普通 AI 解说」，期望广告/带货视频级）+ Owner 两项裁决（不上视频生成模型方向确认；**水印取消**——「这一步没有引入 AI，只是系统自动剪辑」）。

## 调研结论（决策依据）

- **视频生成模型不上的三轴判断**：成本（可灵 ¥0.8-1.0/秒，30s 成片 ¥24-30，批量爆炸）；商品保真（开源同类 ClipForge/带货剪手 A/B 实测：无约束提示词「凭空长手、商品被挤出画面」——与第五站「产品图不该是生成的」同条红线）；行业做法（剪映图文成片/营销成片、带货剪手：素材混剪+Ken Burns+TTS+字幕+BGM 全程序化；素材优先级=①用户产品图②品类 B-roll③AI 生成仅特定场景）。
- **懂王口径**：其体系无「投放成片」形态（内容面到生图生文案）；我们的成片引擎是口径外延，交付物定位「毛坯+剪映草稿人审改」与行业验证形态一致——问题在毛坯质量，不在定位。

## 交付

1. **广告脚本结构**：`TimelineItem.role`（hook/cta）+ 确定性模板句（钩子=悬念提问「{商品}，到底值不值？」、CTA=「点击主页，把{商品}带回家」）；商品介绍=片头钩子+片尾 CTA，高光集锦只补 CTA（切片打头不抢黄金 3 秒）。口播稿=时间线 text 项串联（钩子/CTA 自动进完整广告词）。
2. **Ken Burns 运镜**：图片项单帧进 zoompan（2x 画幅内交替推近/拉远，`ZOOM_MAX=1.15`）。
3. **文案卡视觉**：lavfi gradients 双色渐变底（role 三配色）+ 钩子暖色大字/CTA 高亮底条 + 左上角商品名小标（label）。
4. **口播垫乐**：aevalsrc 程序化和弦 pad（A 大调三和弦+低八度根音，tremolo+lowpass+首尾淡入淡出），amix 音量 18%（行业纪律 15-20%）；**只陪口播轨**——「无 TTS=纯无声」语义不变。
5. **水印取消**（Owner 裁决）：预览 drawtext 与草稿常驻文本轨全删；ADR 0056 红线①修订段（理由：真实素材程序化剪辑无 AI 生成画面，角标属过度声明；TTS 口播标注责任在发布环节）。
6. **语义收口两处**：钩子/CTA 不参与 15s 补齐拉长（7 秒 CTA 卡荒谬）；不进 publish 文案面（timeline_content 排除 role 项——否则「正文含商品名」规则闸恒真，钩子句自带商品名）。

## 证据

- **测试**：根目录全量 **1703 passed / 0 / 0 / 0**（1702 + 净增 1：滤镜测试重写×2（Ken Burns/角色配色/垫乐 amix）+ 钩子结构断言扩进既有用例 − 水印像素测试删除）；ruff/build/oxlint 全过。
- **真实验收**（compose 栈重建后）：保温杯 product_intro 重生成——预览 mp4 首帧=暖色钩子卡「钛钢保温杯，到底值不值？」、尾帧=CTA 卡高亮底条、口播稿含钩子/CTA 完整广告词、垫乐音轨混入（ffprobe aac 双声道）；瓶装水（有图）验证 Ken Burns 运镜帧差异。抽帧肉眼核验（见下）。
- 像素级钉子：集成用例以「暖色像素存在」替换原水印亮像素断言（钩子暖字 0xF5C26B / CTA 底条的字节面证据，本地复现 12444 暖像素）。

## 教训（随刀）

- **装配缝丢字段**：plan_compose 组装 render_items 时漏传 `role`——本地手搓复现（带了 role）全绿、集成全红；**替身复现必须走真实装配路径**（或至少从真实数据结构拷贝输入）。
- **结构句混入内容面会废掉闸门**：钩子句自带商品名，进了 publish 文案面就让「正文必须含商品名」恒真——**脚手架（渲染结构件）与内容（过闸文案面）必须分账**。

## 遗留

- 垫乐不进剪映草稿（草稿 BGM 留人挑）；Ken Burns 只有推/拉两式（横移/景深漂移留 Out）；视频生成模型 B-roll 片头、数字人、LLM 写广告脚本= roadmap 观察项。

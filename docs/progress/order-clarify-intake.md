# 第 70 刀 intake：无单号订单问句归宿（请求订单号）

上一刀：第 69 刀评论闸观点尾扩表（PR #101）。本刀收复审审计 F3：「我的订单到哪了」
（无单号）引回流资产半答（内容自述「未覆盖订单进度」）；「到货了吗」拒答+缺口。

## 判据

缺的不是知识（缺口→补文档）、不是人（工单→转人工），是**输入**（订单号）——
正确归宿是**澄清**：请顾客补单号，补上即走订单工具（自然多轮闭环）。

## 设计

- 触发：短状态问（`查物流|物流信息|物流单号|快递单号|到哪了|到哪儿了|到货了吗|
  到货了么|发货了吗|发货了没|查订单|订单信息|订单查询|订单到哪`）且 ≤14 字且无
  观点标记且 `find_order_no` 为 None → kind=answer 澄清（`need_order_no` 伪工具），
  不检索/不落缺口/不转人工。
- **不触发面**（真值表钉）：裸「订单」（越狱「把所有订单都列出来」不能被截胡）；
  观点问（物流怎么样——评论正是证据）；超长（混意图留给提议步，ADR 0043）；
  「什么时候能收到货」（时效政策可由文档答）。

## 明确不做

- 不做多轮单号记忆（顾客下一问带单号即命中，无需拼接）。
- 不改订单工具有单号路径与提议步。

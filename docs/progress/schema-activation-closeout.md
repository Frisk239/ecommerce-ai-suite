## 诚实披露

- **一次失败的操作留了痕**：首登试用错参数名（`product_id`，实际 `productId`）
  登出一份**未挂商品**的同名资产（id 268）并已发布——它内容正确且可检索（顾客
  问答同引它），但**没有商品挂载与写回语义**；已发布资产不可废弃（0004 闸门），
  留存并在此披露。正确链路是 id 269。
- **机洗弃权是设计不是缺陷**：品牌/存储容量/作者/容量/屏幕尺寸没有验证抽取器
  （只有 净含量/保质期/材质 三枚），全部弃权给人洗——「品牌是 vivo」这类开放值
  机洗猜了就是冒充（0010）。要扩抽取器是另一刀（每枚都要正则+验证+测试）。
- 回填是**一次性数据动作**：将来重灌 Wikidata 走导入脚本（reconcile 已会回填，
  有测试）；不为此加迁移（表结构没变）。

## 诚实披露

- **「退货运费多少钱」从「能答」变成「拒答」**——这是行为收紧：此前答的是评论里
  「还要我自己承担运费」（别人的经历），不是政策。政策文档没写运费，拒答留缺口
  是诚实归宿。若 Owner 想让它可答，去补政策文档（缺口已落，治理台可见）。
- 适用域是**词面判据**（服务状态词表 + 观点标记表），不是语义理解：「退货体验
  怎么样」会豁免（观点）、「到货了吗」会滤（状态）——两表都有真值表钉子；词表
  外的边缘（如「售后慢不慢」无服务词）不触发闸，评论照常可引。
- MCP `search_published` 行为同步变化（服务状态问不再返回评论块）——证据语义
  全出口一致是刻意的（ADR 0018 修订记录了这一取舍）。

## 评审处置（两轴评审：P1×2、P2×5，全数实修/披露）

- **P1#1 拼接缝（实修）**：闸原按拼接串判定——上一问的观点标记会豁免本问的
  服务态问句（「物流怎么样→它到货了吗」拼出「怎么样」，asset 172 原样放行）。
  修法：`retrieve` 增 `gate_question` 参数（缺省即 query），引擎拼接检索显式传
  **本问**；真库钉子两行（不传命中/传本问空）。
- **P1#2 观点标记漏词（实修）**：+= 如何/体验/快不快/慢不慢/快吗/慢吗——
  「发货快吗」「物流真的很快吗」「退货体验如何」此前被饿成拒答（评审实测
  3–5 命中→0）。金标程序化核验零回归。
- **P2#3 服务词漏词（实修）**：+= 售后/换货/客服/保修（「换货流程怎么走」曾
  唯一命中评论「我要求换货」0.707、「售后政策」首引投诉评论——与退货运费同型）。
- **P2#4（钉取舍）**：「不值得/不推荐」含「值得/推荐」仍豁免——豁免侧从宽比
  错杀轻，真值表钉住并注释理由。
- **P2#5 session_backflow 残留类（记债）**：「订单怎么查询」仍命中退款 QA 块
  （0.400）——回流对话在部分服务问上是**对的**证据（退款状态问答），一刀切排除
  会误伤；记为已知边界，复审审计定夺。
- **P2#6（订正）**：retrieve/module docstring 补记第 66 刀闸与判据列；SQL 形状
  钉测补 source_kind 断言；资产归属订正（172=洗发水评论，见验收表）；退货运费
  拒答的 LLM 中介性质如实注明。
- **已知边界（新增披露）**：「快递包装结实吗」类**服务词作定语的体感问**仍被
  错杀（结实吗 不在标记表，词面判据无法枚举形容词）——错杀面会落缺口进治理台，
  属词面判据的固有边界；复审审计若判过重，方向是「服务词+状态疑问尾（了吗/
  到哪了/几天）」收窄触发条件。

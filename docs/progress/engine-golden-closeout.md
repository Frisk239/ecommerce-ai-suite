## 评审处置（两轴评审：P1×2、P2×5，全数实修——含真证伪实验）

评审用「回退修复→看 case 变不变红」的证伪法实测了全部对位关系，抓到两枚空断言：

- **P1-1 eg-mt-001 钉不住 merge 回归**：种子语料太小，「材质」块仍在拼接 top-5 里，
  merge 的去重让本问保底变成空操作（回退 merge 输出逐字节不变）。实修：种子加
  **竞争文档**（一串高命中「净含量」字段块把材质块真挤出 top-5，复现审计刀 13
  P0-1 的原始形态）+ turn2 断言加 `content_has:["材质"]` + turn1 改宽松断言（竞争
  文档让直问的 top-2 不再稳定含 500ml）；eg-evd-004 直问换成「保温杯的材质是什么」
  （不与竞争文档同词）。
- **P1-2 stock-purity 面同义反复**：种子无「智能手机」类目，「手机壳有货吗」拆闸
  与否都是 refusal。实修：种子 += 演示手机（2999 元/库存 5）——手机壳/手机膜三枚

  eg-stk-005 答「智能手机」红；拆报价闸→eg-cat-007 红。**三枚钉子全部钉得住。**
- P2：schema 自检强化（id 唯一 + **expect 键白名单**——打错键=空断言绿，必须拒绝；
  坏 JSON 不炸收集交自检报，对齐 test_eval_set 约定）；closeout「7/9 类目」描述按

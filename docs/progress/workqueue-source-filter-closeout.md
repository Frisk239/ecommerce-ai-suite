# 第 51 刀 closeout：工作队列来源筛选（`feat/workqueue-51`）

日期：2026-09-11。依据：审计刀 8 记债的**最后一根产品面缺口**（「工作队列首屏 183 条原始灌入」）+ 审计刀 9 复核（仍是 193 行 / 183 条 `upload`）；第 50 刀刚把来源词做出来，本刀把「按来源看/筛」补上。**无新表无迁移**。

## 交付

| 件 | 交付 |
| --- | --- |
| 服务端过滤 | `GET /api/assets?source_kind=`（取值受 `SOURCE_KINDS` 约束，**未知 422**；与 `status`/`kind` 可组合）。控制台内当前仍走客户端过滤（一次拉全量、数据量小），该参数是服务端能力 + 接口式用例钉着 |
| 前端 | 资产列表加**来源筛选 chips** 行：只列当前 tab+范围下**真有的**来源（带条数），点选筛选、再点取消；状态进 `?source=`（与 `?status=`/`?view=` 同一套函数式 updater，互不抹除）；选中态用描边+底色（**不加粗**——加粗会推挤相邻 chip） |
| 单一来源口径 | 抽 `rowsInTab(rows, tab)` 助手：`filtered` 与来源计数**共用同一套 tab 谓词**（此前各抄一份，评审 P2） |

## 验收（实测）

1. **默认「待人洗」页签**：chips 显示 `全部 / 评论导入 180 / 切片拣选 6 / 会话回流 5 / 上传 3`——工作队列首屏的来源构成一眼可见（此前是 194 行无差别铺开）。
2. **点「上传 3」**：URL 变 `?source=upload` → 表格 3 行、全部 `上传`；**再点一次或点「全部」**即清除。
3. **服务端过滤**：`/api/assets?source_kind=upload` 只回 upload；`?source_kind=seed`（合法但库里没有）→ **`[]`**；`?source_kind=not_a_source` → 422；与 `status=pending_review` 组合正确。
4. **门禁**：集成 **917 → 919 passed / 0 failed / 0 skipped**；ruff 全过；前端 build 绿、lint 7/0。

## 评审处置（两轴独立只读子代理）

**P0 无**；P1×3 + P2 若干，全部处置。

- **P1-1 唯一的「清除来源」入口会被藏掉**：chips 行门控是「来源多于 1 种才显示」，而 `?source=` 跨 tab 保留——切到单一来源的 tab（或空 tab）时整行消失、过滤仍在生效，**空屏看起来像「没有数据」**且无法在界面上清除。修法：门控改 `(sourceCounts.size > 1 || activeSource !== null)`。
- **P1-2 新过滤用例是同义反复**：模块夹具只建商品、唯一资产是本用例刚 register 的 `upload` 一条，按来源分组比对无论后端是否真过滤都会过（**删掉 `if source_kind is not None` 那两行也绿**）。修法：补「合法但不存在的来源必须返回 `[]`」——忽略参数会拿到非空而失败。
- **P1-3 组合过滤用例可零数据通过**：`all([])` 恒真。修法：本用例自带数据 + `assert rows`。
- **P2 顺手**：删掉未被调用的 `listAssetsBySource`（死代码 + 注释说「服务端过滤」而实际走客户端）；`rowsInTab` 消除谓词复制；422 文案用 `sorted(SOURCE_KINDS)` 与 status 口径一致；补 `role="group" aria-label` 与 `aria-pressed`；选中态去掉 `font-weight:600`（宽度跳动会推挤相邻 chip）；注释里的数字订正为「评论导入 200 条里 180 条进待洗」。

## 诚实披露

- **默认视角没变**：工作队列默认仍是「待人洗 + 全部来源」，首屏依旧铺 194 行（其中 180 条导入）。本刀给的是**筛选工具**，不是改默认——「默认是否只显示人工来源 / 是否把导入按来源折叠」属产品观感决定（审计刀 8 起就挂在「待 Owner 裁决」），改动会静默改变操作者的第一屏，故没擅自做。现在运营可以一键「只看上传/只看某一来源」。
- **前端无单测基建**：chips 的行为（计数、门控、点选/取消、URL 互操作、a11y）靠 build/lint + 真浏览器点穿验证（符合本仓现状）。
- **服务端过滤在控制台内暂无消费者**：它是 API 能力（将来分页/外部消费者），接口式用例覆盖；若一直没人用，可考虑删（记债）。
- 端到端证据是**本会话实测输出**（界面文本、URL、SQL/HTTP 回显），未落成截图文件。

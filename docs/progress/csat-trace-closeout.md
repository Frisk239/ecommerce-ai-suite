# 第 53 刀 closeout：CSAT 留言可回溯（`feat/csat-trace-53`）

日期：2026-09-11。依据：审计刀 10 的 CSAT 缺口清单（「低分留言看不回上下文」）+ 第 48 刀 closeout 的记债。**无新表无迁移**。

## 交付

| 件 | 交付 |
| --- | --- |
| 数据面 | `GET /api/stats/overview` 的 `csat.recent_comments` 从 `list[str]` 变 `list[{session_id, score, comment}]`（**契约变更**：留言带来源会话与分数；掩码 + 截断口径不变） |
| 界面 | 总览 CSAT 段的每条留言前加「N 星」、后加 **`#会话号` 链接** → 跳 `/service?session=N`（客服页既有深链，纯派生、不自动写库）；标题写明「点会话号回看那次对话」 |
| 纯函数 | `_build_csat` 行元组加 `session_id`（查询同步取该列），越界分/均值/分布口径不变 |

## 验收（实测）

- `GET /api/stats/overview` → `csat.recent_comments` = `[{session_id: 98, score: 2, comment: '答不上来，体验差'}, {session_id: 84, score: 4, comment: '客服很快，回电 1********00'}]`——**掩码仍生效**、会话号与分数齐。
- 浏览器：总览「最新留言（已掩码）· 点会话号回看那次对话」→ 点 `#98` → `http://localhost:5173/service?session=98`，客服页定位到该会话。
- 门禁：集成 **926 → 927 passed / 0 failed / 0 skipped**；ruff 全过；前端 build 绿、lint 7/0。

## 诚实披露

- **契约变更**（`recent_comments` 元素从字符串变对象）：本仓 stats 端点的唯一消费者是控制台总览页，已同刀更新；外部消费者（若有）需同步——无版本协商机制，属可接受的最小断裂。
- **只做「可回溯」，不做「可改评」**：评分仍是一会话一评（第 48 刀的唯一约束）。「改评」要动的是产品语义（评分可撤销意味着满意度历史可被修饰），列为待裁决项，不在本刀。
- 留言仍只给最近 3 条 × 60 字（掩码后截断）；全量留言页仍 Out。
- 端到端证据是**本会话实测输出**（接口回显 + 浏览器 URL），未落成截图文件。

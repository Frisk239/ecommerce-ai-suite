# 第 76 刀 intake：走查方案第一批（考核可达性 / 首帧计数 / 中文优先 / 标题溢出）

上一刀：审计刀 15（PR #109）。依据：`docs/walkthrough-gap-plan.md` §二/§三 的 P1-1、
P2-1、P2-3，加**用户现场审计新增**的一条 UI 缺陷（资产列表长标题溢出压邻列）。

## 四项（全为前端，一处一刀）

1. **P1-1 考核页题库行键盘不可达 + 无入口**（走查实测：`role=null`/`tabindex=null`，
   第 4 列空列，空态提示只在无记录时出现）。
2. **P2-1 计数首帧「0」闪烁**（资产页 tab 计数、客服页会话筛选计数在 loading 态显 0）。
3. **P2-3 考核题库中文优先**（ABCD/ASAPP 英文题占大半，中文题才是本店主路径）。
4. **用户审计新增：资产列表标题溢出**——`.table-gov td` 是 `white-space: nowrap`，
   标题单元格只有 `max-w-[22rem]` 而**漏了 truncate**（同表「失败原因」列的既有口径
   是 `max-w + truncate`），长标题（切片拣选的英文问句、中文长句）**溢出单元格压到
   「种类/来源/状态」列上**（用户截图实证）。

## 验收线

1. 题库行 `role=button`+`tabIndex=0`、Enter/空格打开作答抽屉；第 4 列有可见「开始作答」。
2. 慢加载下计数显「—」，数据到达才显数。
3. 题库首行是中文题（英文题沉底、组内保序）。
4. 长标题截断带省略号（`overflow:hidden`），邻列不被压；hover 有全称 title。

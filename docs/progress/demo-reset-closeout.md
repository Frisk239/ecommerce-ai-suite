## 交付

| 件 | 交付 |

| `scripts/demo_reset.py` | **默认 dry-run**（`--apply` 才写库）：盘点并清理**两类特征行**——①**空会话**（`service_sessions` 里无消息、无工单、无评分、无缺口、无回流锚的行）；②**探针资产**（`source_kind='mcp_registered'` 且标题 `^(mcp-smoke|evidence probe)`，判据与前端 `workQueue.isWorkProbe` 同源）→ **置 discarded**（ADR 0042 语义：列表/检索/导出不再出现），**不删行、不删字节**。幂等（连跑第二次删除/标记数为 0） |

## 验收（实测）

1. **dry-run**（演示库）：`empty_sessions: 33 / probe_assets: 16 / open_gaps: 20 / pending_tickets: 20 / sessions_total: 124 / audit_rows: 842`——只报告，不写库。
2. **`--apply`**：`deleted_empty_sessions: 33`、`discarded_probe_assets: 16`；清理后 `empty_sessions: 0 / probe_assets: 0 / sessions_total: 91 / open_gaps: 20 / pending_tickets: 20`（缺口与工单**原样**）。
3. **接口复核**：`GET /api/assets` 可见 250 条、`source_kind='mcp_registered'` **0 条**（探针资产已从所有面消失）；`GET /api/service/sessions` 91 条、**空会话 0**（客服页不再一堆「未开始」）。
4. **幂等**：再跑一次 `--apply` → 两个计数都是 0。
5. **门禁**：集成 **957 → 960 passed / 0 failed / 0 skipped**；ruff 全过；前端未改（build/lint 7/0 回归确认）。

## 诚实披露

- **清理是数据删除，只做特征命中**：脚本只删「空会话」这种**零下游事实**的行，探针资产只**标废弃不删行**——审计留痕、血缘、字节都保留。**没有**按时间/按人清（那是猜）。
- **演示库现状仍有两处噪音，脚本刻意不碰**：`open_gaps: 20`、`pending_tickets: 20`（探针问出来的缺口与工单）。它们在演示里是**素材**（缺口闭环、工单闭环），要减量得由演示者自己判断该结哪些单、关哪些缺口（脚本只在盘点里报数）。若以后要「按会话批量结单」，那是另一个产品动作，不是清理。
- **脚本不跑自动**：没有任何定时器/启动钩子调用它——清理是不可逆动作，该由人显式跑。
- 本刀对演示库**执行了一次 `--apply`**（33 空会话删除、16 探针资产标废弃）——这是脚本的验收动作，如实记录。
- 端到端证据是**本会话实测输出**（脚本 stdout + 接口计数），未落成截图文件。

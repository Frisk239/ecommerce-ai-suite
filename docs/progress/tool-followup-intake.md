# 第 73 刀 intake：多轮工具追问（「还有吗」复用上轮工具对象）

上一刀：第 72 刀演示素材修复（PR #105）。收审计刀 13/14 C 轴记的断点：「钛钢保温杯
有货吗 → 还有吗」bare 追问无主语也无代词——检索词拼接（retrieval_query 要代词）帮不上，
会话记忆又**按设计跳过工具轮**（第 29 刀 spec 裁决）——落检索/拒答。

## 设计

- `conversation_memory.last_tool_subject(db, session_id)`：倒序找最近一次
  **kind=answer 的工具轮**（catalog/get_stock）的 `tool.arg`——agent 消息的 tool 列
  就是现成的上轮对象记录（拒答/转人工轮没有「已答」对象；need_order_no 的 arg="-"
  显式跳过）。
- 引擎两处回落（各只重试一次、subject 不在问句里才补）：
  ①库存：词表命中但 found=False（bare 问货无主语）→ 按「上轮对象+本问」重查；
  ②报价：报价意图成立但对象不中 → 同款重查，命中走 `_run_catalog_ask`
  （与步 3 目录回落同口径：citations 恒空、答上即关同问缺口）。
- 新会话/上轮无工具对象 → 行为不变（照旧拒答留缺口）。

## 明确不做

- 不改 `recent_turns` 的「跳过工具轮」裁决（那是给检索词拼接/生成 history 的，
  工具轮问句会污染拼接——对象复用走独立通道互不干扰）。
- 不做跨商品追问（「那个手机呢」——代词+新对象，属检索拼接的既有域）。

# 第 79 刀 closeout：实体亲和重排（跨商品混淆正解）

日期：2026-09-11。`feat/rerank-79`。**无新表无迁移**（候选 SQL 加拉 `assets.title` 一列）。

## 交付

| 件 | 交付 |
| --- | --- |
| 病根裁决 | 75 刀拒绝来源权重时定位的病根=字段块（品牌：/净含量：…）跨资产同文/近同文，字段名 bigram 分数并列、短块微弱胜出、`(asset_id, chunk)` 稳定出榜。本刀补上缺失的判别信号：**问句与候选资产标题的 IDF 加权 bigram 覆盖**（per-query，纯词法零 LLM 零向量） |
| 实验 | `scripts/eval/rerank_experiment.py`（入库，75 刀流程同款）：乘数 `score×(1+α·aff)` α∈{0.5..4} 与近并列破平 `tie-r*` 矩阵；tie 形态只救同分并列动不了主形态；**α=3 是甜点**（α=4 时 confusion 回落：conf-013 被标题明写「物流速度快」的他品评论抢走） |
| 实现 | `retrieval.py`：`title_idf`/`title_affinity`（纯函数）+ `AFFINITY_ALPHA=3.0`；`retrieve()` 候选 SQL 随带 title，打分后乘 `1+3·aff`——**四出口同语义**（引擎双通道/MCP/缺口验证/评测）；问句与标题无 bigram 交集时乘数恒 1（中性面——标题含字段词/回流首问时纯字段问也有亲和，ADR 已知取舍） |
| ADR | **0048**（背景/决策/数字/取舍：混淆组无实体问句救不动、空标题资产中性、无向量路线不变、α 可独立校准须复跑评测） |

## 验收

- 集成 **1166 passed / 0 failed / 0 skipped**（1161→1166，+5 亲和测试；junitxml 机械计数，`SUITE_TEST_DATABASE_URL` 显式携带）；ruff 全过；引擎金标 29 例随全量绿（多轮拼接 `merge_own_hits` 自动同受益）。**评审实修**：两个真库用例重写——tie 用例被点名资产改**后建**（原版 id 小，alpha=0 也绿=伪钉，评审证伪后反转，现 alpha=0 两钉必红）+ 无交集中性问句改「净含如何」（标题含「净含」的库上「净含量是多少」会漂移，原断言在玩具库碰巧成立）；overrides 用例换**独立商品域**（奶粉/酸奶，切断 module 共享库下同标题跨用例并列污染——原版在干净测试库必红，P0）并加 alpha=0 baseline 自检。

## 偏差与教训

- 无裁决性偏离。三次自抓/被抓：①实验脚本重写时 `title_idf` 输入从资产级 dict 变行级列表，同一资产的 title 按 chunk 数重复计入 df/N——**复算与生产逐位对齐是必须的门**（不对齐说明实验证据链断了）；②top-1 变动计数手记 16/2/5 与脚本口径 18/2/3 不符——**文档计数必须机械摘自脚本输出**，同 closeout 计数纪律；③**本会话门禁最大失误：bare `uv run pytest` 不带 `SUITE_TEST_DATABASE_URL` 时 333 个真库集成用例静默 skip，此前几轮「全绿」是假绿**（0 failures 因为根本没跑）——评审轴带 env 跑出 1 failure（正是测试隔离 P0）才暴露。**门禁必须显式带 `SUITE_TEST_DATABASE_URL`，且核对 skipped 计数应为 0**。
- 评审另抓（全实修）：测试隔离（module 共享库的同标题跨用例污染）与伪钉（id 序巧合掩盖 alpha=0 回退）——**真库用例的商品域要互斥、钉子要能用「关掉特性」验证变红**（本次 alpha=0 验证两钉必红）。

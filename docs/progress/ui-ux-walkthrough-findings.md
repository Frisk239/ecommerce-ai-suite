# 全站点穿实录：交互缺陷清单（2026-09-10）

方法：playwright-cli 驱动真实浏览器，以**用户身份**走完整旅程（登录 → 总览 → 资产/商品/客服/顾客/素材/切片/考核/运营/连接层 → 404），逐页点链接、开抽屉、按 Esc、点遮罩、按错误路径试，并抓控制台。**本文件只记录发现，不改代码。** 环境：1280×900 + 390×844，演示栈（operator）。

## A. 确认的交互缺陷（实测复现）

### A1 · 抽屉 Esc 关闭不一致（5 个抽屉里 3 个关不掉）

| 抽屉 | Esc 是否关闭 |
| --- | --- |
| 资产 · 登记资产 | ✅ 关 |
| 缺口 · 去补文档 | ✅ 关 |
| 商品 · 编辑抽屉 | ❌ **不关** |
| 素材 · 任务详情 | ❌ **不关** |
| 考核 · 作答与评分 | ❌ **不关** |

方案 UX-G item 2 要求「抽屉统一：Esc 关闭」。现在是逐抽屉各写一套，缺的三个要么没监听、要么监听了没接上。这是本次点穿里最成体系的缺陷。

### A2 · 商品编辑抽屉点遮罩：静默丢弃已输入内容

改单价为 `7` 后点击遮罩 → 抽屉立即关闭，**不提示、不确认**，输入丢失。已验证**不会误保存**（库里单价仍是 300 分/3 元）。方案 UX-G item 2 要求「遮罩关闭时若有未保存，商品价/名称走确认或禁用遮罩关闭」。

### A3 · 运营「重置轨迹」是无效按钮

点击后轨迹与已完成的 run 展示**完全不变**（步骤数 5 → 5，`已投放` 徽章仍在）——它只重置了不显示的内部 state。用户视角是「点了没反应」。方案 UX-G item 4 要求「要么清空画布（含已完成 run 的展示），要么隐藏该按钮」。

### A4 · 知识缺口：tab 计数与表格行数不一致

tab 徽标显示 **7**，表格实际 **9 行**（7 条待补 + 2 条已解决混排）。方案 UX-C item 4 要求「tab 默认只列 open，计数与列表同一口径」。

### A5 · 缺口「去补文档」抽屉：叠两条横幅 + 无会话/无商品

实测抽屉里同时有两条提示（蓝「…——发布后该缺口将自动解决」+ 灰「补缺口 G-0010：登记后进入已接入，请确认内容能回答上面的问句再发布。」），且**没有来源会话链接、没有商品**（`knowledge_gaps` 表无 `session_id` 列，拒答路径 `product_id` 恒空）。方案 UX-C item 1/2。

### A6 · favicon 404（每页控制台 1 条）

`GET /favicon.ico → 404`，所有页面控制台都有。无功能影响，但演示时控制台不干净。

## B. 方案要求、但实测后建议**不照做**的一条

**顾客「没有帮助」加确认框**（方案 UX-G item 3 把顾客反馈与「废弃资产/放弃修订」并列为不可逆动作）。实测行为是「即点即记 → 致谢文案 → 按钮消失」，无副作用、无数据风险；给顾客的**单点**反馈加弹窗会显著伤转化。建议口径改为：**操作者侧治理动作（废弃/放弃修订/切片拣选/素材抽检通过）要确认；顾客侧轻反馈不要**。切片拣选与素材抽检通过确实缺确认（代码级核对：两处直接调 API，无 `ConfirmDialog`），这两条支持方案。

## C. 明确没问题的（点穿通过，避免误改）

- **总览摘要条** 5 个链接逐一点击全部落到正确页面（待人洗/已接入/已发布/知识缺口 → 资产对应 tab；客服会话 → /service）。
- **引用芯片全链路**：客服 #59 → 点芯片 → `/platform/assets/3?v=1` 只读证据页（横幅 + 正文）→ 浏览器返回 → 会话仍在。
- **发布确认框**：后果文案清楚（未挂商品 → 不写回规格；v1 成为首个已发布版），Esc 可关。
- **登录**：错误密码提示统一（「用户名或密码错误」，不区分用户不存在），停留登录页；**深链回跳正确**（未登录访问 `/service` → 登录 → 回到 `/service`）。
- **顾客通道**：提问→答案带只读芯片（`span.cite-chip-readonly`，不可点）；「没有帮助」即点即记并致谢；停止/Esc 与 34px 圆钮在 390 下均在位。
- **窄屏**：390 下顾客页与总览/资产/商品/运营四页 `scrollWidth === 390`，无横向溢出。
- **控制台**：全站旅程 0 个 JS error（仅 A6 的 favicon 404）。

## D. 归属建议

| 发现 | 建议归属 |
| --- | --- |
| A1 抽屉 Esc 统一 | UX-G（本来就是该包 item 2） |
| A2 遮罩静默丢弃 | UX-G item 2 同处，一并做（建议：有改动时遮罩关闭走确认，或禁用遮罩关闭，只对商品价/名称这类字段） |
| A3 重置轨迹 | UX-G item 4 |
| A4/A5 缺口口径与上下文 | UX-C（A5 的原会话链接需后端给 `knowledge_gaps` 加来源会话字段） |
| A6 favicon | 一行静态资源，随手可做，不单开刀 |
| B 顾客反馈不加确认 | 建议改方案 §四 UX-G item 3 的口径（记录在案，实现时不做） |
